# Responsive Design Quick Reference Guide\n\n## Mobile, Tablet & Desktop Optimization\n\n### Breakpoint Summary\n\n| Device | Width | Grid Cols | Example |\n|--------|-------|-----------|----------|\n| **Mobile** | < 640px | 1 | iPhone SE, Galaxy S21 |\n| **Tablet** | 641-1024px | 2 | iPad, Galaxy Tab |\n| **Desktop** | 1025px+ | 3+ | Laptop, Monitor |\n\n---\n\n## 1. Using Responsive Typography\n\n### CSS Variables (Predefined)\n```css\n--text-xs:    0.75rem   (12px)\n--text-sm:    0.875rem  (14px)\n--text-base:  1rem      (16px)\n--text-lg:    1.125rem  (18px)\n--text-xl:    1.25rem   (20px)\n--text-2xl:   1.875rem  (30px)\n--text-3xl:   2.25rem   (36px)\n--text-4xl:   3rem      (48px)\n--text-5xl:   3.75rem   (60px)\n```\n\n### Usage\n```html\n<h1>Normal heading</h1>\n<h1 class=\"text-responsive-lg\">Responsive large heading</h1>\n<p class=\"text-responsive\">Responsive paragraph</p>\n<small class=\"text-responsive-sm\">Responsive small text</small>\n```\n\n### Automatic Scaling\n```css\n/* These scale automatically based on viewport */\n.text-responsive { font-size: clamp(1rem, 2vw, 1.5rem); }\n.text-responsive-lg { font-size: clamp(1.5rem, 4vw, 3rem); }\n```\n\n---\n\n## 2. Creating Responsive Buttons\n\n### HTML\n```html\n<button class=\"btn btn-primary\">Click Me</button>\n<a href=\"#\" class=\"btn btn-secondary\">Learn More</a>\n```\n\n### Features\n- ✅ Automatic 48px minimum height on mobile\n- ✅ Full width on mobile, auto on tablet/desktop\n- ✅ Touch-friendly padding\n- ✅ Responsive font sizing\n\n### Customize Button Size\n```css\n/* Mobile buttons */\n@media (max-width: 640px) {\n    .custom-btn {\n        padding: 12px 16px;  /* Smaller on mobile */\n        width: 100%;\n    }\n}\n\n/* Desktop buttons */\n@media (min-width: 1025px) {\n    .custom-btn {\n        padding: 14px 32px;  /* Larger on desktop */\n        width: auto;\n    }\n}\n```\n\n---\n\n## 3. Responsive Form Inputs\n\n### HTML\n```html\n<input type=\"email\" placeholder=\"Enter your email\" required>\n<textarea placeholder=\"Your message\"></textarea>\n<select>\n    <option>Choose an option</option>\n</select>\n```\n\n### Features\n- ✅ Font size 16px on mobile (prevents zoom)\n- ✅ Minimum 44px height (touch-friendly)\n- ✅ Clear focus states\n- ✅ Custom dropdown styling\n\n### Input Focus Styling\n```css\n/* Blue outline on focus */\ninput:focus {\n    border-color: #4F46E5;\n    box-shadow: 0 0 0 3px rgba(79, 70, 229, 0.1);\n}\n```\n\n---\n\n## 4. Responsive Grids\n\n### Mobile-First Grid\n```html\n<div class=\"grid\">\n    <div>Card 1</div>\n    <div>Card 2</div>\n    <div>Card 3</div>\n</div>\n```\n\n### Automatic Behavior\n```\nMobile:  [Card1]\n         [Card2]\n         [Card3]\n\nTablet:  [Card1] [Card2]\n         [Card3]\n\nDesktop: [Card1] [Card2] [Card3]\n```\n\n### Custom Grid\n```css\n/* Define custom grid */\n.my-grid {\n    display: grid;\n    grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));\n    gap: 1.5rem;\n}\n\n/* Will automatically adapt to all screen sizes */\n```\n\n---\n\n## 5. Responsive Spacing\n\n### Using Spacing Classes\n```html\n<!-- Responsive spacing that adapts to screen size -->\n<section class=\"spacing-responsive\">Large content area</section>\n<div class=\"spacing-responsive-sm\">Small spacing</div>\n```\n\n### Manual Spacing\n```css\n/* Mobile */\n@media (max-width: 640px) {\n    section { padding: 1rem; margin: 1rem; }\n}\n\n/* Tablet */\n@media (min-width: 641px) and (max-width: 1024px) {\n    section { padding: 2rem; margin: 1.5rem; }\n}\n\n/* Desktop */\n@media (min-width: 1025px) {\n    section { padding: 3rem; margin: 2rem; }\n}\n```\n\n### Using CSS Variables\n```css\nsection {\n    padding: var(--space-lg);\n    margin: var(--space-xl);\n}\n```\n\n---\n\n## 6. Hiding/Showing Content\n\n### Show/Hide by Device\n```html\n<!-- Hide on mobile, show on larger screens -->\n<div class=\"hide-mobile\">Desktop-only content</div>\n\n<!-- Show only on mobile -->\n<div class=\"show-mobile\">Mobile-only content</div>\n\n<!-- Hide on tablet and larger -->\n<div class=\"show-tablet hide-desktop\">Tablet content</div>\n```\n\n### Manual Implementation\n```css\n/* Hide on mobile */\n@media (max-width: 640px) {\n    .desktop-only { display: none; }\n}\n\n/* Show on tablet */\n@media (min-width: 641px) {\n    .mobile-only { display: none; }\n}\n```\n\n---\n\n## 7. Touch-Friendly Navigation\n\n### Hamburger Menu\n```html\n<button class=\"hamburger\" aria-label=\"Menu\">\n    <span></span>\n    <span></span>\n    <span></span>\n</button>\n\n<nav class=\"navbar\" id=\"navbar\">\n    <!-- Menu items -->\n</nav>\n```\n\n### JavaScript Handler\n```javascript\nconst hamburger = document.querySelector('.hamburger');\nconst navbar = document.getElementById('navbar');\n\nhamburger.addEventListener('click', () => {\n    navbar.classList.toggle('active');\n    hamburger.setAttribute('aria-expanded', \n        hamburger.getAttribute('aria-expanded') === 'true' ? 'false' : 'true'\n    );\n});\n```\n\n---\n\n## 8. Responsive Images\n\n### Lazy Loading\n```html\n<!-- Images load only when visible -->\n<img src=\"image.jpg\" alt=\"Description\" loading=\"lazy\">\n```\n\n### Responsive Image Sizes\n```html\n<!-- Image scales with container -->\n<img src=\"image.jpg\" alt=\"Responsive\" class=\"img-responsive\">\n\n<!-- Maintains aspect ratio -->\n<img src=\"image.jpg\" alt=\"Thumbnail\" class=\"img-thumbnail\">\n```\n\n### Picture Element (Advanced)\n```html\n<picture>\n    <source srcset=\"mobile.jpg\" media=\"(max-width: 640px)\">\n    <source srcset=\"tablet.jpg\" media=\"(max-width: 1024px)\">\n    <img src=\"desktop.jpg\" alt=\"Responsive image\">\n</picture>\n```\n\n---\n\n## 9. Accessibility on All Devices\n\n### Touch Target Sizes\n```css\n/* All interactive elements: minimum 48px */\nbutton, a, input {\n    min-height: 48px;\n    min-width: 48px;\n}\n```\n\n### Focus States\n```css\ninput:focus,\nbutton:focus,\na:focus {\n    outline: 2px solid #4F46E5;\n    outline-offset: 2px;\n}\n```\n\n### Keyboard Navigation\n```css\n/* Support Tab key navigation */\na:focus-visible,\nbutton:focus-visible,\ninput:focus-visible {\n    outline: 2px solid #4F46E5;\n}\n```\n\n---\n\n## 10. Media Query Quick Reference\n\n### Breakpoint Syntax\n```css\n/* Mobile First Approach */\n/* 1. Default: Mobile styles */\nbody { font-size: 15px; }\n\n/* 2. Add tablet styles */\n@media (min-width: 641px) {\n    body { font-size: 16px; }\n}\n\n/* 3. Add desktop styles */\n@media (min-width: 1025px) {\n    body { font-size: 17px; }\n}\n```\n\n### Viewport Conditions\n```css\n/* Hide on mobile */\n@media (max-width: 640px) {\n    .desktop-only { display: none; }\n}\n\n/* Tablet only */\n@media (min-width: 641px) and (max-width: 1024px) {\n    /* Tablet styles */\n}\n\n/* Desktop and larger */\n@media (min-width: 1025px) {\n    /* Desktop styles */\n}\n\n/* Landscape orientation */\n@media (orientation: landscape) {\n    /* Landscape styles */\n}\n\n/* Touch devices */\n@media (hover: none) and (pointer: coarse) {\n    /* Touch device styles */\n}\n\n/* Desktop/Mouse devices */\n@media (hover: hover) and (pointer: fine) {\n    /* Desktop styles */\n}\n```\n\n---\n\n## 11. Testing Checklist\n\n### Mobile Testing\n- [ ] Text readable without zoom\n- [ ] Buttons at least 48x48px\n- [ ] Forms don't trigger zoom on focus\n- [ ] Navigation works (hamburger menu)\n- [ ] Images scale properly\n- [ ] No horizontal scroll\n\n### Tablet Testing\n- [ ] 2-column layout active\n- [ ] Proper spacing between elements\n- [ ] Touch targets comfortable\n- [ ] Landscape mode works\n- [ ] Images at correct size\n\n### Desktop Testing\n- [ ] 3-column layout active\n- [ ] Hover effects work\n- [ ] Proper whitespace\n- [ ] Readability optimal\n- [ ] Full navigation visible\n\n---\n\n## 12. Common Patterns\n\n### Responsive Container\n```css\n.container {\n    width: 100%;\n    max-width: 1280px;\n    margin: 0 auto;\n    padding: 0 var(--space-md);\n}\n\n@media (min-width: 641px) {\n    .container { padding: 0 var(--space-lg); }\n}\n```\n\n### Responsive Card\n```css\n.card {\n    background: white;\n    border-radius: var(--border-radius-medium);\n    padding: var(--space-md);\n    box-shadow: var(--shadow);\n    transition: all var(--transition-fast);\n}\n\n@media (min-width: 1025px) {\n    .card:hover {\n        transform: translateY(-5px);\n        box-shadow: var(--shadow-lg);\n    }\n}\n```\n\n### Responsive Flex\n```css\n.flex-container {\n    display: flex;\n    flex-direction: column;\n    gap: var(--space-md);\n}\n\n@media (min-width: 641px) {\n    .flex-container {\n        flex-direction: row;\n        gap: var(--space-lg);\n    }\n}\n```\n\n---\n\n## Need Help?\n\nRefer to:\n- Full documentation: `RESPONSIVE-IMPROVEMENTS.md`\n- CSS variables: `styles/global.css`\n- Responsive framework: `styles/responsive-improvements.css`\n- Template meta tags: `meta-tags-template.html`\n\n---\n\n**Last Updated**: June 2, 2026\n**Framework Version**: 1.0\n
